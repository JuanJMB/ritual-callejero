# Ritual Callejero

Primera cápsula de Ritual Callejero: Cráneo y Última Canción.

Web estática con campaña editorial, catálogo de dos prendas y galerías ampliables. Incluye diseño adaptable a celular y escritorio.

## Publicación

Compatible con GitHub Pages. Publicar desde la rama `main`, carpeta raíz (`/`). El archivo `.nojekyll` permite servir directamente HTML, CSS, JavaScript e imágenes.

## Estado

Prototipo visual de la marca. Las imágenes de campaña son visualizaciones generadas con IA. No hay compras, pagos ni cuentas habilitadas.
